DEVELOPER CENCORD PORTFOLIO

GitHub Pages setup:
1. Create a new GitHub repository (for example: developer-cencord-portfolio).
2. Upload index.html, style.css, and the assets folder.
3. Open the repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish your site.

Before publishing:
- Open index.html and replace your-email@example.com with your real contact email.
- Add your real project links or screenshots when ready.
- Keep assets/profile.jpg in the assets folder so your profile photo loads.
